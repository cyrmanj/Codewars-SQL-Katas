# 🧠 Codewars SQL Katas

This repository contains my **solutions and attempts to various SQL katas on [Codewars](https://www.codewars.com/)**.

The goal of this repo is to:
- Practice and improve SQL skills
- Explore different problem-solving approaches
- Keep a personal reference of useful SQL patterns and techniques

## 📌 About the Solutions

- All solutions are written in **SQL**
- Some katas may have **multiple attempts or partial solutions**
- Queries are optimized for **clarity and learning**, not necessarily the shortest possible answer
- Difficulty levels may vary (from beginner to advanced)

## 🗂 Repository Structure

Katas are typically organized by:
- Kata name or Codewars slug  
- Difficulty level (when applicable)

Each file corresponds to a single Codewars kata.

## ⚠️ Disclaimer

These solutions are:
- For **learning and reference purposes only**
- Not intended to encourage copying during active Codewars challenges

If you're working on a kata yourself, try solving it first before checking solutions here 🙂

## 🚀 Technologies Used

- SQL (PostgreSQL / MySQL / generic SQL, depending on kata)
